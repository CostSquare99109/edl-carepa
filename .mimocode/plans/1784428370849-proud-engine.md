# Fix: Grok Build error de autenticación

## Problema
Grok Build (v0.2.103) falla al intentar autenticarse vía OIDC contra `https://auth.x.ai/.well-known/openid-configuration`. El cliente HTTP interno de Grok (Rust/reqwest) no puede conectarse a ese endpoint en Termux/Android, aunque `curl` funciona normalmente.

Logs confirman:
```
"auth failed","ctx":{"error":"error sending request for url (https://auth.x.ai/.well-known/openid-configuration)"}
```

## Solución
Usar API key en vez de OIDC. Grok acepta `XAI_API_KEY` como alternativa al login OIDC.

### Pasos:

1. Obtener API key desde https://console.x.ai
2. Configurar la variable de entorno:
   ```bash
   export XAI_API_KEY="xai-..."
   ```
3. Para persistencia, agregar a `~/.bashrc` o `~/.zshrc`:
   ```bash
   echo 'export XAI_API_KEY="xai-..."' >> ~/.bashrc
   ```
4. Ejecutar grok:
   ```bash
   grok
   ```

### Archivos relevantes
- `~/.grok/config.toml` — configuración actual (solo tiene installer)
- `~/.grok/docs/user-guide/01-getting-started.md` — documentación oficial

### Verificación
```bash
export XAI_API_KEY="xai-..."
grok --version  # debe funcionar
grok             # debe iniciar sin error de auth
```

## Alternativa (si no se tiene API key)
El login OIDC necesita abrir un navegador. En Termux esto no funciona directamente. Se podría:
1. Usar `termux-open-url` para abrir la URL de auth en el navegador del celular
2. Copiar el token manualmente
3. Guardarlo en `~/.grok/auth.json`

Pero la API key es la solución más simple y recomendada.
