## 📌 Notas importantes

- Esta carpeta es **documentación, no código**. No modifica `backend/`, `frontend/`, `database/`, ni los archivos raíz del proyecto.
- Las transcripciones originales siguen en `transcripciones_cnsc/` (carpeta hermana) como **fuente primaria**. Esta carpeta las **consolida, organiza y cruza** con los hallazgos del proyecto.
- Para cambios de código, usar `14-futuro-del-proyecto.md` como guía.
- Para reportar errores o proponer mejoras a esta documentación, abrir un PR con la entrada correspondiente en `CHANGELOG.md`.
