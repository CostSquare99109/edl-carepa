## 3. Marco normativo colombiano

### 3.1 Constitución y leyes

| Norma | Descripción | Aplicación |
|---|---|---|
| **Constitución Política de Colombia** | Artículo 125 — Mérito como principio de acceso y permanencia. | Base constitucional. |
| **Ley 909 de 2004** | Sistema General de Carrera Administrativa. | Numeral 3 del artículo 51 (régimen de calificación no satisfactoria). |
| **Ley 1960 de 2019** | Requisitos para encargos. | Modifica requisitos de la Ley 909. |
| **Ley 734 de 2002** | Código Disciplinario Único (art. 33 numeral 4 — calificaciones como antecedente). | Régimen disciplinario. |

### 3.3 Acuerdos CNSC

| Norma | Descripción | Vigencia |
|---|---|---|
| **Acuerdo 137 de 2010** | Sistema Tipo anterior. | Modificado parcialmente por Acuerdo 561/2016. |
| **Acuerdo 565 de 2016** | Sistema Tipo previo al 617. | Vigente solo para período feb 2018 - ene 2019. |

## 9. Glosario de términos

| Término | Definición |
|---|---|
| **EDL** | Evaluación del Desempeño Laboral. |
| **EDL APP** | Aplicativo oficial de la CNSC para gestionar la EDL. |
| **CNSC** | Comisión Nacional del Servicio Civil. |
| **LNR** | Libre Nombramiento y Remoción. |
| **Acuerdo 617** | Norma que rige el Sistema Tipo actual (2018). |
| **Concertación** | Proceso bilateral de fijación de compromisos entre evaluador y evaluado. |
| **Compromisos funcionales** | Resultados, productos o servicios medibles que el servidor debe cumplir. |
| **Compromisos comportamentales** | Competencias, habilidades y actitudes observables en el ejercicio del empleo. |
| **Período anual** | Del 1 de febrero al 31 de enero del año siguiente. |
| **Período de prueba** | Etapa inicial del empleado público en carrera administrativa (4 meses si es plazo fijo, depende de la naturaleza del cargo). |
| **Comisión Evaluadora** | Integrada por jefe inmediato + evaluado + un servidor LNR. |
| **Evaluación parcial eventual** | Evaluación generada por una causal específica (cambio de evaluador, separación temporal, etc.). |
| **Calificación definitiva** | Resultado final de la evaluación del período (anual, prueba o extraordinaria). |
| **Sobresaliente** | Nivel ≥ 90%. |
| **Satisfactorio** | Nivel > 65% y < 90%. |
| **No satisfactorio** | Nivel ≤ 65%. |
| **Notificación personal** | Diligencia mediante la cual se pone en conocimiento del evaluado la calificación definitiva. |
| **Recurso de reposición** | Recurso ante el evaluador. |
| **Recurso de apelación** | Recurso ante el inmediato superior del evaluador. |
